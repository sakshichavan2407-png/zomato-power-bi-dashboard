# zomato-power-bi-dashboard
Interactive Power BI dashboard analyzing Zomato restaurant data across cities. Covers KPIs (restaurants, ratings, votes, average cost), online delivery share, price-range trends, and city-wise geographic analysis across 3 report pages.

# Zomato Restaurant Analysis - Power BI Dashboard
An interactive 3-page Power BI dashboard that explores Zomato restaurant data:
- **Executive Overview:** KPI cards, restaurant location map, and filters
- **Restaurant & Customer Insights:** rating vs. votes, top restaurants, online delivery split
- **Geographical & Locality Analysis:** city-wise ratings and customer votes
